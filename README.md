# Tenant logos

Public logos for **allowed marketing partners**. Each folder is a tenant slug; files inside are the partner’s logo assets.

Use these files only for partners listed here. Do not add or publish a logo unless that tenant is an allowed marketing partner.

**Licence:** the Logos remain the property of the respective partners. They are **not** licensed for further use. See [LICENSE](LICENSE).

## Layout

```
{tenant-slug}/{logo-file}
```

- **Folder name** — tenant identifier (slug)
- **File(s)** — logo artwork (PNG, JPEG, or SVG)

Some tenants have more than one file (for example a transparent SVG and a version with a background).

## Usage

Raw files are available from this repository, for example:

```
https://raw.githubusercontent.com/MUV-Digital/tenants/main/{tenant-slug}/{logo-file}
```
